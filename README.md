## 기능 목록

### 도메인

#### **Lotto**
> - [x] 생성 시에 6개의 숫자를 가진다.
> 
> **기능**
> - [x] 당첨 로또와 비교하여 몇 개의 번호와 일치하는지 계산한다.
> - [x] 보너스 번호를 포함하고 있는지 확인한다.
> - [x] 로또 번호를 오름차순으로 정렬하여 반환한다.
> 
> **검증**
> - [x] 로또 번호는 1~45 사이의 숫자여야 한다.
> - [x] 로또 번호는 중복될 수 없다.

#### **WinningLotto**
> - [x] 6개의 당첨 번호와 1개의 보너스 번호를 가진다.
> 
> **기능**
> - [x] 구매한 로또(Lotto)를 받아 등수(Rank)를 판별한다.
> 
> **검증**
> - [x] 당첨 번호는 6개여야 한다.
> - [x] 보너스 번호는 1개여야 한다.
> - [x] 보너스 번호는 당첨 번호 6개와 중복될 수 없다.

#### **LottoMachine**
> 
> **기능**
> - [x] 구입 금액을 받아서, 로또 개수를 계산한다.(1,000원 단위)
> - [x] 구매 개수만큼 로또를 발행한다.
> 
> **검증**
> - [x] 구입 금액은 1,000원 단위여야 한다.
> - [x] 구입 금액은 1,000원 이상이어야 한다.

#### **LottoResult**
> 
> **기능**
> - [x] 여러 장의 로또와 당첨 번호를 기반으로, 등수별 당첨 횟수를 집계한다.
> - [x] 총 구매 금액 대비 총 당첨금을 기반으로, 수익률을 계산한다.
> - [x] 수익률은 소수점 둘째 자리에서 반올림한다.

#### **Rank**
> - 1등부터 5등, 그리고 꽝을 정의한다.
> 
> **기능**
> - [x] 일치하는 숫자 개수와 보너스 숫자 일치 여부를 받아 어떤 등수인지 판별한다.
> - [x] 각 등수별 당첨 금액을 가진다.

### 애플리케이션 흐름  

#### **InputView**
> - [x] 로또 구입 금액을 입력받는다.
> - [x] 당첨 번호(쉼표로 구분)를 입력받는다.
> - [x] 보너스 번호를 입력받는다.

#### **OutputView**
> - [x] 구매한 로또 개수를 출력한다.
> - [x] 구매한 로또들의 번호(오름차순)를 모두 출력한다.
> - [x] 당첨 통계(등수별 개수)를 정해진 형식으로 출력한다.
> - [x] 총 수익률을 정해진 형식으로 출력한다.
> - [x] 예외 발생 시, "[ERROR]"로 시작하는 메시지를 출력한다.

#### **LottoGameController**
> - [x] 구입 금액을 입력받아 로또를 발행한다.
> - [x] 당첨 번호와 보너스 번호를 입력받아 당첨 번호 객체를 생성한다.
> - [x] 발행된 로또들과 당첨 번호를 비교하여 당첨 통계(Result)를 생성한다.
> - [x] 계산된 통계와 수익률을 출력한다.
> - [x] 입력 과정에서 예외(`IllegalArgumentException`) 발생 시, 에러 메시지를 출력하고 해당 부분의 입력을 다시 받는다.
